## 部署摘要
核心模型：MediaTek Breeze-ASR-26（聯發科發布之語音辨識模型）
執行環境：Windows 11 / PowerShell
主要技術：
1. Python + PyTorch
2. Hugging Face transformers 套件
3. FFmpeg（用於音訊格式轉換與預處理）

硬體與效能優化：利用 NVIDIA 顯示卡進行 半精度（FP16）推理，將顯存控制在 6GB 限制內，確保順利於本地端穩定運作。

主要腳本與功能：
1. 撰寫 transcribe.py 自動化腳本。
2. 支援傳入音訊檔案，自動將台語語音轉錄為文字，並將辨識結果直接輸出儲存為 .txt文字檔。

## 使用程式碼

```python
import sys
import torch
from transformers import pipeline

def transcribe_audio(audio_path, output_txt="result.txt"):
    print("正在載入 MediaTek Breeze-ASR-26 模型...")
    
    # 建立 ASR pipeline，配置半精度 (FP16) 以控制顯存於 6GB 內
    asr_pipeline = pipeline(
        "automatic-speech-recognition",
        model="MediaTek-Research/Breeze-ASR-26",
        torch_dtype=torch.float16,
        device="cuda" if torch.cuda.is_available() else "cpu"
    )

    print(f"開始辨識音訊: {audio_path}")
    result = asr_pipeline(audio_path)
    text_output = result["text"]

    # 輸出結果至 .txt 檔案
    with open(output_txt, "w", encoding="utf-8") as f:
        f.write(text_output)

    print(f"辨識完成！結果已儲存至 {output_txt}")
    print(f"辨識內容：\n{text_output}")

if __name__ == "__main__":
    if len(sys.argv) > 1:
        audio_file = sys.argv[1]
        transcribe_audio(audio_file)
    else:
        print("請提供音訊檔案路徑，例如: python transcribe.py input.mp3")

```

9成以上的對話都可以分析出來，在沒有對話的時候會收錄環境聲音，導致誤辨識成相近的文字。建議先將語音段話做分割，並透過其他方式將語音辨識成的文字做後處理。
